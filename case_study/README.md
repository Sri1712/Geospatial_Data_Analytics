# Geospatial Data Analytics Case Study

This case study demonstrates how geospatial data can be prepared, explored,
analysed, and visualized to identify spatial patterns and support
data-driven decision-making.

## Objectives

- Load and inspect geospatial datasets.
- Clean and prepare spatial and tabular data.
- Perform exploratory spatial analysis.
- Create maps and other visualizations.
- Communicate findings and limitations clearly.
